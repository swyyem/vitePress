Affix 固钉 ​

将页面元素固定在特定可见区域，支持顶部/底部固定，支持指定滚动容器。

基础用法 ​

在页面滚动时固定元素到顶部。

固定在底部 ​

设置 position="bottom" 将元素固定到容器底部。

偏移距离 ​

通过 offset 设置固定时距顶部/底部的距离（单位 px）。

监听固定状态 ​

通过 @change 事件获取固定状态变化。

监听滚动事件 ​

通过 @scroll 事件获取实时滚动位置与固定状态。
