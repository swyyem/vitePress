## 一、AI 编程基础认知

### 1. AI 编程的本质

**回答要点：**

**核心定位：**

- AI 不是替代开发者，而是**增强开发者能力**
- 从"写代码的人"转变为"审查和引导代码的人"
- 提升开发效率和代码质量

**实际价值：**

```
传统开发：
需求 → 设计 → 编码 → 测试 → 修复
(编码阶段耗时 60-70%)

AI 辅助开发：
需求 → 设计 → AI生成 → 审查 → 优化 → 测试
(编码阶段耗时降至 20-30%)
```

### 2. Vibe Coding 概念

**回答要点：**

**核心理念：**

- **Vibe** = 氛围、感觉、直觉
- 通过自然语言描述需求，AI 理解意图并生成代码
- 开发者专注于**架构设计、逻辑审查、质量把控**

**思维转变：**

```
传统思维：
"我要怎么写这个功能？"
↓
逐行编写代码
↓
调试修复

Vibe Coding 思维：
"我需要什么功能？"
↓
用自然语言描述
↓
AI 生成初稿
↓
审查优化
↓
迭代完善
```

### 3. AI 工具生态

**回答要点：**

**工具分类：**
| 类型 | 代表工具 | 特点 |
|------|---------|------|
| IDE 插件 | GitHub Copilot、通义灵码 | 代码补全、注释生成 |
| AI IDE | Cursor、Windsurf | 深度集成、项目理解 |
| 对话式 | ChatGPT、Claude | 架构设计、问题解答 |
| 专用工具 | Devas、Aider | 终端操作、自动化 |

### 4. 大语言模型原理

**回答要点：**

**基本原理：**

- **Transformer 架构**：注意力机制
- **预训练**：海量代码数据训练
- **微调**：针对编程任务优化
- **上下文学习**：In-context Learning

**代码理解能力：**

```javascript
// 模型能理解：
1. 语法结构
2. 设计模式
3. 最佳实践
4. 常见错误
5. 性能优化
```

### 5. Prompt Engineering

**回答要点：**

**核心原则：**

1. **明确角色**：设定 AI 的身份
2. **清晰目标**：具体说明要做什么
3. **提供上下文**：给出必要信息
4. **设定约束**：限制输出范围
5. **示例驱动**：提供参考样例

**Prompt 模板：**

```
角色：你是资深前端开发工程师
任务：创建一个 Vue 3 表格组件
要求：
  - 支持分页、排序、筛选
  - 使用 TypeScript
  - 包含完整类型定义
  - 添加 JSDoc 注释
上下文：项目使用 Element Plus 组件库
输出：完整的 .vue 文件代码
```

### 6. Context Window

**回答要点：**

**上下文窗口：**

- **定义**：模型一次能处理的 token 数量
- **影响**：能理解的代码量、对话历史长度
- **优化策略**：
  - 精简代码片段
  - 分层提供信息
  - 使用引用而非全文

**实战技巧：**

```
❌ 错误做法：
把整个项目文件都贴进去

✅ 正确做法：
1. 提供相关接口定义
2. 说明使用场景
3. 给出关键代码片段
4. 说明期望的输出格式
```

### 7. Token 机制

**回答要点：**

**Token 概念：**

- Token 是模型处理的基本单位
- 英文：1 token ≈ 0.75 个单词
- 中文：1 汉字 ≈ 1-2 tokens
- 代码：1 token ≈ 1-3 个字符

**成本计算：**

```
输入 tokens + 输出 tokens = 总消耗
影响：
  - 响应速度
  - 使用成本
  - 上下文长度限制
```

### 8. 温度参数调优

**回答要点：**

**Temperature 参数：**

- **0.0-0.3**：确定性高，适合精确任务
- **0.4-0.7**：平衡创造性和准确性
- **0.8-1.0**：创造性高，适合头脑风暴

**应用场景：**

```javascript
// 代码生成：temperature = 0.2-0.3
// 确保输出稳定可靠

// 创意方案：temperature = 0.7-0.8
// 激发更多可能性

// 文档编写：temperature = 0.5
// 平衡准确性和可读性
```

### 9. AI 编程优势

**回答要点：**

**核心优势：**

1. **速度提升**：编码速度提升 2-5 倍
2. **知识广度**：快速掌握新技术栈
3. **减少重复**：自动化样板代码
4. **学习加速**：即时获得解释和示例
5. **质量提升**：发现潜在问题
6. **文档完善**：自动生成注释和文档

**数据支撑：**

```
GitHub 调研数据：
- 55% 的开发者编码速度更快
- 60% 的任务完成更快
- 75% 的工作更愉悦
- 平均编码时间减少 40%
```

### 10. AI 编程局限

**回答要点：**

**主要局限：**

1. **理解深度有限**：复杂业务逻辑可能出错
2. **上下文限制**：无法理解整个项目全貌
3. **最新知识滞后**：训练数据有时间截止
4. **安全隐患**：可能生成有漏洞的代码
5. **版权问题**：训练数据可能涉及开源协议
6. **过度依赖**：开发者能力可能退化

**应对策略：**

```
1. 保持批判性思维
2. 必须进行代码审查
3. 核心逻辑人工编写
4. 安全相关代码人工审核
5. 定期更新 AI 工具
6. 持续提升自身能力
```

## 三、Vibe Coding 实践

### 21. Vibe Coding 核心理念

**回答要点：**

**核心思维：**

```
传统编程：
开发者 = 代码编写者
重点：语法、API、实现细节

Vibe Coding：
开发者 = 架构师 + 审查者
重点：需求理解、架构设计、质量把控
```

**工作流程：**

1. **需求分析**：理解业务需求
2. **Prompt 设计**：用自然语言描述
3. **AI 生成**：获得初稿代码
4. **代码审查**：检查逻辑和安全性
5. **迭代优化**：与 AI 对话改进
6. **测试验证**：确保功能正确

### 22. 思维模式转变

**回答要点：**

**转变关键：**

```

   }
```
