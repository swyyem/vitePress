一、AI 编程基础认知 ​

1. AI 编程的本质 ​

回答要点：

核心定位：

  • AI 不是替代开发者，而是增强开发者能力
  • 从"写代码的人"转变为"审查和引导代码的人"
  • 提升开发效率和代码质量

实际价值：

传统开发：
需求 → 设计 → 编码 → 测试 → 修复
(编码阶段耗时 60-70%)

AI 辅助开发：
需求 → 设计 → AI生成 → 审查 → 优化 → 测试
(编码阶段耗时降至 20-30%)

    • 精简代码片段
    • 分层提供信息
    • 使用引用而非全文

实战技巧：

1. 提供相关接口定义

7. Token 机制 ​

回答要点：

Token 概念：

  • Token 是模型处理的基本单位
  • 英文：1 token ≈ 0.75 个单词
  • 中文：1 汉字 ≈ 1-2 tokens
  • 代码：1 token ≈ 1-3 个字符

成本计算：

输入 tokens + 输出 tokens = 总消耗
影响：
  - 响应速度
  - 使用成本
  - 上下文长度限制

8. 温度参数调优 ​

回答要点：

Temperature 参数：

  • 0.0-0.3：确定性高，适合精确任务
  • 0.4-0.7：平衡创造性和准确性
  • 0.8-1.0：创造性高，适合头脑风暴

应用场景：

javascript
// 代码生成：temperature = 0.2-0.3
// 确保输出稳定可靠

// 创意方案：temperature = 0.7-0.8
// 激发更多可能性

// 文档编写：temperature = 0.5
// 平衡准确性和可读性

10. AI 编程局限 ​

回答要点：

主要局限：

  1. 理解深度有限：复杂业务逻辑可能出错
  2. 上下文限制：无法理解整个项目全貌
  3. 最新知识滞后：训练数据有时间截止
  4. 安全隐患：可能生成有漏洞的代码
  5. 版权问题：训练数据可能涉及开源协议
  6. 过度依赖：开发者能力可能退化

应对策略：

1. 保持批判性思维
2. 必须进行代码审查
3. 核心逻辑人工编写
4. 安全相关代码人工审核
5. 定期更新 AI 工具
6. 持续提升自身能力
